# ADRs do serviço identity

As decisões de arquitetura deste serviço estão nas ADRs e RFCs transversais da Fase 4 (ADR-F4-01 a ADR-F4-14 e RFC-F4-01 a 03), no [`fiap-soat-mecanica-k8s`](https://github.com/fiap-postech-soat-lf/fiap-soat-mecanica-k8s/tree/main/docs/arquitetura-fase4/adr). As que mais pesam aqui: ADR-F4-07 (JWT RS256), ADR-F4-12 (notificações no Identity) e ADR-F4-13 (seeds).

Não há ADR específica deste repositório. Se surgir uma, ela entra nesta pasta no formato `NNNN-titulo.md` (contexto, decisão, consequências).
